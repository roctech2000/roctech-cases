## How to write a case

1. Duplicate `_template.md` and rename it to `<case-slug>.md`.
2. Complete every heading in the template.
3. Place images in an `assets/<case-slug>/` folder and reference them relatively.
4. Add a row to the **Index** table above.
5. Keep it factual and outcome-focused.
